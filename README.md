# Satellite Demo

Temporary project name for a three-person, twenty-hour satellite maneuver planning demo.

**Current state: planning and documentation. No application has been built.**

Start with [Handoff/README.md](Handoff/README.md). The `Handoff` folder is the shareable documentation packet for teammates and their AI assistants. Its [STATE.md](Handoff/STATE.md) records completed work and unverified targets.

The original source documents are preserved in [Handoff/reference](Handoff/reference/README.md). Current package specifications supersede their conflicting build instructions.
